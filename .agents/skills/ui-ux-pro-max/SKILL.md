# UI/UX Pro Max Design Intelligence (v2.15.0)

## Core Philosophy
1. **Design System First**: Determine design tokens (colors, typography, spacing, surface elevations) before assembling code.
2. **Context & Archetype Match**: Tailor aesthetics to organization type. For non-profit & youth service organizations (e.g., Interact / Rotary), prioritize warmth, credibility, engagement, clear community impact, and accessible volunteer calls-to-action.
3. **Fail-Closed Accessibility (WCAG 2.1 AA)**:
   - Text contrast ratio ≥ 4.5:1 against backgrounds (3:1 for large display text ≥ 24px/18pt bold).
   - Touch targets ≥ 44×44px with adequate padding.
   - Visible 2px focus outlines with 2px offset for keyboard navigation.
   - Semantic DOM hierarchy (single H1 per page, sequential H2 -> H3).
4. **Data Integrity & Zero Hallucination**:
   - Never fabricate historical records, statistics, dates, or beneficiary numbers.
   - Use strongly typed schema models and structured input forms/slots for real data injection.
